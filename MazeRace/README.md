# Race in the Maze

A maze racing game developed in Java using Swing.

## Features

- Two-player gameplay
- Collision detection
- Tile-based map system
- Keyboard controls
- Main menu
- Character customization
- JUnit testing

## Technologies

- Java
- Java Swing
- JUnit 5
